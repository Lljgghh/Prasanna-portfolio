2. Supabase project URL and publishable key are already configured.
3. The Supabase Auth user must be cpro3316@gmail.com. Keep public signups disabled.
4. Confirm the public Storage bucket exists with exact name portfolio-posters. It must allow public reads and authenticated admin uploads/deletes.
5. Table portfolio_projects must allow public SELECT and admin INSERT/UPDATE/DELETE.
6. Open https://YOUR-SITE/admin.html in Chrome to log in. Do not open the file inside WPS Office.

This package is not live until deployed to your website. Never share your password or service_role key.
